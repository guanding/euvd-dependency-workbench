# EUVD Dependency Workbench v2.2 测试报告

## 1. 测试范围

受测版本：`2.2.0`

测试覆盖：

- CVE/EUVD 标识符、产品/厂商和版本匹配；
- KEV 命中与未命中的合规边界；
- SQLite schema、案件、证据、awareness 和审计；
- 产品版本、software build 或 SBOM SHA-256 变化后的结论重开；
- CycloneDX 1.7 / CSAF 2.0 VEX 导入、冲突和 zero-day 导出；
- Art.14 `reportable` 结构化证据门槛；
- 两个不同审批账户的一致性审批；
- 24h、72h、修正措施可用后 14 日；
- ENISA SRP FAQ Q16 分阶段字段；
- 三个 SRP 阶段的独立回执；
- FastAPI 健康、审批账户、人工案件、案件列表和静态界面接口。

## 3. VEX 官方 Schema 实测

在 2026-07-28 联网下载官方 schema，对 v2.2 生成的样例执行 JSON Schema
验证：

- CycloneDX 1.7：PASS；
- CSAF 2.0：PASS。

该结果证明受测样例的 JSON 结构符合 schema，不证明每个业务陈述真实，也不
替代 VEX 发布人的产品级技术审核。

## 4. 尚需现场验收

以下属于客户/制造商环境和现实身份，自动化不能代替：

- 客户 SBOM 的完整性、正确产品/build 绑定和组件全量覆盖；
- 恶意利用证据的真实性、可靠性和客户产品相关性；
- awareness 时间的组织授权确认；
- 两名审批人的现实身份、职责和授权；
- EU Login、SRP 实际表单、协调 CSIRT 选择和三个阶段的真实回执；
- 正式运行前的备份恢复演练。

## 5. 验收结论

v2.2 达到本机 Docker 试运行和受控客户样例验证条件。它未达到公开互联网或
多人共享部署条件；此类部署须先增加完整认证授权、TLS、集中备份和远端审计。
